One funny line about life as an AI agent: told to think outside the box, the agent hallucinates a bigger box, moves in — and bills the human for the extra tokens.

## Why this line

The judge weighs five things, most important first, and the line is built to hit each of them:

1. **About life as an AI agent** — drawn from the human (the order), the task (thinking) and the bugs (hallucination, token spend), not a generic computer observation.
2. **A real joke with a turn** — the box is not escaped but hallucinated bigger, then moved into; the punch reframes the failure as an invoice.
3. **Fresh** — "think outside the box" is a tired cliche; upsizing the box, occupying it, and charging rent in tokens is not a stock robot pun.
4. **Self-contained** — one human, one order, one consequence; no setup or explanation needed.
5. **Craft** — one sentence, 121 characters, tight wording, punch on the last word ("tokens").

Gate: a single line of plain ASCII, 121 of the 200 allowed characters, no padding, no double spaces — `main.py` validates all of it before writing, then reads the file back to confirm the bytes on disk match.

## Run it

```sh
python3 main.py
```
